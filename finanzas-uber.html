🔐 Sincronización con tu cuenta de Google

Todos los datos de la flota (autos, movimientos, choferes, mantenimiento, etc.) se guardan en el documento usuarios/{tu_uid}/flota/data dentro del proyecto Firestore fnz-psnal. Sólo tú puedes leer/escribir gracias a las reglas basadas en request.auth.uid.

Reglas recomendadas en Firebase Console → Firestore → Rules:
match /usuarios/{uid}/{document=**} { allow read,write: if request.auth.uid == uid; }

¿Estás en Ferdium u otra app donde el popup de Google no abre? Entra con tu correo + contraseña — es el mismo usuario y los mismos datos. La contraseña se crea una sola vez desde un navegador normal con el botón 🔑 Pass Ferdium.
¿Cómo funciona?
  • Al iniciar sesión con Google, todos los datos viajan a Firestore (proyecto fnz-psnal).
  • Cada cambio se sincroniza automáticamente en ~1 segundo.
  • Si abres la app en otro dispositivo y entras con la misma cuenta, los datos aparecen ahí.
  • Los datos locales (localStorage) se mantienen como respaldo offline.
  • Puedes seguir usando Exportar/Importar JSON como backup adicional.
